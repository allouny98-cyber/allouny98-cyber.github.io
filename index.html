Database Design with SQL

Designed and built a fully normalized relational database for a video games catalog in SQL Server. Implemented primary/foreign keys, indexes and constraints across 4 connected tables (Games, Developers, Genres, Platforms), then wrote analytical T-SQL queries combining JOINs, CTEs and window functions to surface market insights.

Python & Jupyter Analysis

Exploratory data analysis on the video games database. The Jupyter notebook connects directly to SQL Server through SQLAlchemy, loads the joined dataset into Pandas, cleans and transforms it, and produces a series of clear visualizations (price distribution, top genres, developer activity, release trends) using Matplotlib and Seaborn.
