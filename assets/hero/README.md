# Images du hero (slider plein écran)

Dépose ici les photos du slider de la page d'accueil `electropack-nouveau.html`.

## Fichiers attendus
- `hero-1.jpg`
- `hero-2.jpg`
- `hero-3.jpg`
- `hero-4.jpg`

## Recommandations
- Format **paysage**, ~1600×900 px (16:9).
- Sujets : électricité, chantier, bâtiment/tertiaire, hôtellerie — éviter les photos de stock génériques.
- Compresser pour le web : **≤ 300 Ko** par image.
- Les fichiers sont référencés en chemin absolu `/assets/hero/hero-N.jpg`.

Tant qu'une image est absente, un **dégradé marine temporaire** s'affiche automatiquement à sa place (aucune image cassée). Il suffit de déposer les fichiers ci-dessus pour que le slider les utilise, sans aucune modification de code.
